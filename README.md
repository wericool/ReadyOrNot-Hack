# Ready Or Not — Solo ESP

Внешний ESP для одиночной игры Ready Or Not. Меню и подписи на русском языке.

[Скачать готовый архив](https://github.com/wericool/ReadyOrNot-Solo-ESP/releases/latest) · [English](README.en.md)

## Функции

- Рамки врагов и гражданских с отдельными переключателями.
- Скелет: 16 суставов, 15 соединений; включается независимо от рамок.
- Числа текущего/максимального HP и полоска HP — два отдельных переключателя.
- Расстояние до объектов, диапазон отображения 25–500 метров.
- Состояния: активен, сдаётся, задержан, без сознания, мёртв.
- Отдельные переключатели арестованных (по умолчанию скрыты) и мёртвых / без сознания.
- Улики и брошенное оружие: жёлтые маркеры с названиями.
- Объекты для доклада и изначально лежащие пострадавшие: голубые маркеры; для пострадавших — скелет и состояние.
- Выбор цвета врагов, сохранение настроек.
- Подписи с подложкой, разнесением пересечений и линиями к объектам.
- Скрытие при переключении на другое приложение.
- Отключение телеметрии при обнаружении сетевой сессии.

## Совместимость и ограничения

Проверено в одиночной миссии на Steam build **24942528**, версия меню **133804**, Unreal Engine **5.3**, разрешение **3440×1440**. Проверено обнаружение изначально лежащего пострадавшего класса IncapacitatedHuman.

Отрисовка — отдельное прозрачное окно Windows Forms/GDI, без перехвата DirectX игры. Отдельный запуск на DX11 пока не проверен: совместимость с любым графическим режимом не гарантируется. Рекомендуется оконный режим без рамки. Эксклюзивный полный экран, другие разрешения и будущие версии игры требуют дополнительной проверки.

Проект предназначен для одиночной игры. Проверка World.NetDriver отключает телеметрию сетевой сессии; это не гарантия совместимости со всеми сетевыми конфигурациями.

Скелет может обновляться с задержкой из-за отключения анимаций невидимых объектов самой игрой. Неизвестные кости пропускаются. Рамки основаны на капсуле персонажа. У отдельных типов объектов нет HP. Не каждый декоративный предмет является игровой уликой. Исчезновение собранных/доложенных объектов зависит от игровых флагов; каждый переход состояния отдельно не проверялся.

## Установка готовой версии

1. Закрой игру. Скачай ZIP из Releases и распакуй в отдельную постоянную папку с правом записи. Архив содержит оверлей и закреплённую версию UE4SS.
2. Открой PowerShell в распакованной папке.
3. Укажи **свой** путь к корню игры. Пример команды:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-ESP.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Ready Or Not"

4. Запусти игру обычным способом, выбери одиночную миссию и запусти Start-ESP.cmd.
5. Меню вызывается по Insert.

Папку оверлея после установки не перемещай: мод записывает телеметрию в неё. После перемещения повтори установку с закрытой игрой.

Установщик добавляет dwmapi.dll, каталог ue4ss и мод RoNESP в ReadyOrNot\Binaries\Win64. Сохраняет предыдущую версию собственного Lua-файла в backups. Чужая proxy DLL или другая версия UE4SS останавливает установку. Сохранения, игровые EXE и PAK не изменяются.

## Управление

| Кнопка | Действие |
| --- | --- |
| Insert | Открыть/закрыть меню |
| ↑ / ↓ | Выбрать пункт |
| ← / → / Enter | Изменить параметр |
| F6 | Включить/выключить весь ESP |
| End | Завершить оверлей |

Клавиши работают, когда игра на переднем плане. Меню имеет разделы «Общее», «Персонажи», «Здоровье», «Объекты». Tab переключает разделы. Вкладки и строки также нажимаются мышью; вне меню мышь проходит в игру. Для свободного курсора при необходимости открой паузу игры. Настройки сохраняются в settings.json.

## Отключение загрузчика

Закрой игру и укажи свой путь:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Disable-ESP.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Ready Or Not"

Повторное включение:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Enable-ESP.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Ready Or Not"

Отключение переименовывает только DLL с хешем загрузчика из пакета в dwmapi.dll.RoNESP-disabled. Оно отключает весь UE4SS, включая другие моды под этим загрузчиком. Файлы мода и сохранения остаются. End закрывает только оверлей.

## Сборка из исходников

Требуется Windows x64 с .NET Framework 4.x. Visual Studio не нужна: build.ps1 использует системный compiler Framework64.

    powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File .\Download-UE4SS.ps1
    powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-ESP.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Ready Or Not"

UE4SS закреплён на **v3.0.1-1152-ge3ba1016**. Скрипт скачивает официальный архив и проверяет SHA-256. Если архив удалён из экспериментального релиза upstream, используй полный архив этого проекта. Автоматического обновления зависимости нет.

## Как это работает

mod/Scripts/main.lua выполняется в игре через UE4SS. Отражённые функции Unreal находят персонажей через IsSuspect/IsCivilian, EvidenceComponent, ReportableActor и IncapacitatedHuman. Для потоковых уровней мод сопоставляет Level.OwningWorld, получает кости и здоровье, проецирует координаты через ProjectWorldLocationToScreen.

С целевым интервалом 16 мс мод пишет telemetry.json; списки объектов обновляются примерно раз в секунду. src/Overlay.cs читает координаты и рисует прозрачное окно. Если данные старше 600 мс, метки скрываются. Телеметрия и настройки остаются локальными, приложение не отправляет их на сервер.

## Если ничего не отображается

- Проверь одиночную миссию и включение ESP через F6.
- Проверь, что игра на переднем плане, загрузчик не отключён.
- Проверь появление и обновление telemetry.json рядом с RoN-ESP.exe.
- После перемещения папки повтори установку с закрытой игрой.
- Проверь дальность и переключатели гражданских, улик, пострадавших, неактивных персонажей.
- Обновление игры может потребовать исправлений.
- Другие UE4SS-моды могут конфликтовать; установщик не заменяет чужую версию загрузчика.

В issue укажи Steam build, разрешение, режим окна, настройки и шаги воспроизведения. Перед публикацией логов убери личные пути, имена пользователя и другие персональные данные.

### Оптимизация v1.1.0

Скрытые категории, дальность и отключение скелета учитываются до расчёта костей и проекций. Настройки подхватываются модом примерно за полсекунды. Оверлей пропускает повторный разбор неизменившегося файла и переиспользует перья скелета. «Данные» в меню показывает частоту принятых кадров, а не FPS игры.

В текущей проверке одиночной миссии наблюдалось около 25 Гц до изменения и 38–39 Гц после. Это пример замера, не гарантия частоты для любой сцены. Сбор остаётся ограничен игровым потоком и нагрузкой. Отдельно проверены отрисовка меню, обработчики мыши и независимость фильтров; фактическое управление мышью в игре в этом обновлении не подтверждено из-за ошибки захвата окна.
