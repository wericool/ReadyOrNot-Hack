# Changelog

## 1.0

- Ready or Not hack by ericool: one launcher with all ESP and gameplay functions.
- Seven menu categories: ESP, Characters, Display, Objects, Player, Speed and Info.
- All measured statistics and connection diagnostics moved to Info.
- Automatic graceful exit when the attached game process ends.
- Suspects/civilians, arrested and inactive filters, boxes, skeletons, head dot, independent numeric HP and HP bar.
- Evidence, dropped weapons, incapacitated victims, bodies awaiting report/cuff actions, and active door traps.
- Current magazine ammo with persistent horizontal/vertical position sliders.
- Free camera, SWAT retaliation prevention and station weapon firing/grenade throwing.
- Independent collection, skeleton, health/state and rendering intervals.
- Standalone EXE, automatic game discovery, bundled UE4SS, saved settings and signature-checked native changes.
